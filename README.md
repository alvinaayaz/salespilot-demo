# SalesPilot

A portfolio demo of a lightweight sales workspace: prospect list, rule-based lead scoring, priority snapshot, editable reply drafts, pipeline status controls, and CSV export.

## Run locally
```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Deploy
This repository includes `render.yaml` for a free Render web service. Connect this repository in Render and deploy the Blueprint.

## Important
Portfolio prototype only. No external AI provider, CRM, email, phone, or live customer database. All prospect records are fictional. Drafts are suggestions and are not sent.
